# Daily Cash Calculator

Android app for tallying game-room machine meters at the end of each shift.
Records IN / OUT per machine, flags a FINISH lower than its START, and rolls
the shift totals up into weekly and monthly reports.

## Install

1. Open the link above on the tablet and download the file.
2. Tap the downloaded `DailyCashCalculator.apk`. Android will ask whether to
   allow installs from this source — turn the switch on.
3. Installing over an older version keeps the data already entered on the device.

## Notes

- Everything runs on the device. No account, no network needed to use it.
- START readings are carried over from the previous shift and cannot be edited.
- Weekly and monthly reports list every submission, so a shift that was closed
  twice is visible.
